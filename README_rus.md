# 🤖 Telegram-бот с Google Gemini

Демонстрационный проект с малым набором возможностей: интеграция **Telegram Bot API** (aiogram 3) с искусственным интеллектом **Google Gemini**.

Пользователь отправляет сообщение, бот передаёт его в Gemini и возвращает ответ.

## Возможности

- ответы на вопросы и объяснение сложных тем;
- консультации, рекомендации, идеи для проектов;
- помощь в обучении, генерация текстов и планов;
- индикатор «печатает…» во время генерации ответа;
- автоматическое разделение длинных ответов (лимит Telegram — 4096 символов);
- обработка ошибок API с понятными сообщениями пользователю.

## Приватность

- история диалога **не хранится**: каждое сообщение обрабатывается отдельно;
- **база данных и файлы** для хранения данных не используются;
- тексты сообщений **не логируются** (в логах только служебная информация);
- после ответа никакие данные пользователя не сохраняются.

> Важно: запросы передаются в Google Gemini API и обрабатываются по правилам Google.

## Установка и запуск

1. **Получите токен Telegram-бота**: напишите [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. **Получите ключ Gemini API** в [Google AI Studio](https://aistudio.google.com/apikey).
3. **Установите зависимости** (рекомендуется виртуальное окружение):

   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env`** на основе примера и впишите свои ключи:

   ```bash
   cp .env.example .env            # Windows: copy .env.example .env
   ```

   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   GEMINI_API_KEY=ваш_ключ_gemini
   ```

5. **Запустите бота**:

   ```bash
   python main.py
   ```

6. Откройте бота в Telegram, отправьте `/start` и задайте любой вопрос.

## Настройка

| Что | Где |
|---|---|
| Модель Gemini | переменная `GEMINI_MODEL` в `.env` (по умолчанию `gemini-flash-latest`) |
| Поведение и стиль ответов | константа `SYSTEM_PROMPT` в `main.py` |
| Креативность ответов | параметр `temperature` в `generate_response()` |
| Приветствие | константа `WELCOME_TEXT` в `main.py` |

Актуальный список моделей: <https://ai.google.dev/gemini-api/docs/models>

## Возможные проблемы

- **«Не заданы TELEGRAM_BOT_TOKEN и/или GEMINI_API_KEY»** — проверьте, что файл `.env` лежит рядом с `main.py`.
- **Ошибка 429** — превышены лимиты бесплатного тарифа Gemini API, подождите или проверьте квоты в AI Studio.
- **Ошибка 404 / модель не найдена** — укажите актуальное название модели в `GEMINI_MODEL`.
- **Бот не отвечает** — убедитесь, что не запущен второй экземпляр бота с тем же токеном.

## Безопасность

Не публикуйте файл `.env` и не коммитьте его в репозиторий — добавьте `.env` в `.gitignore`.
